# A dataset with population by sex and age, from Insee's 2016 population forecast (central scenario)

A dataset with population by sex and age, from Insee's 2016 population
forecast (central scenario)

## Usage

``` r
FRInseePopulationForecast2016
```

## Format

A data frame with 14036 observations and 4 variables:

- age0101:

  age at January, 1st of the year

- year:

  year

- sex:

  sex ('male' or 'female')

- popx:

  population at each year, age, sex
