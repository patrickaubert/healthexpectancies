# Runs examples of uses of the package

Runs examples of uses of the package

## Usage

``` r
runExample(example = "projprevalence")
```

## Arguments

- example:

  name of the example (default is 'projprevalence' : a Shiny app
  displaying forecasting of prevalences and DFLE for France)

## Value

launches the app

## Examples

``` r
if (FALSE) { # \dontrun{
runExample()
} # }
```
