# healthexpectancies: Functions to calculate Health and Disability-free Life Expectancies (DFLE) using Sullivan method

The package provides useful functions to calculate Disability-free Life
Expectancies (DFLE) using Sullivan method. Calculations are based on
Newcastle University's Practical Guide, initially created in the
Euro-REVES project and subsequently updated with funding from the
European Commission for the European Health Expectancy Monitoring Unit
(EHEMU) and the European Health and Life Expectancy Information System
(EHLEIS). The package also includes present and forecasted data tables
for France, functions that smooth prevalences observed by age bracket,
and functions that project prevalences and DFLE, under hypotheses on the
evolution of DFLE or with models estimated on past observations.
