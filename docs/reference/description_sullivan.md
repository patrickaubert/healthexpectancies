# A description of the variables in the dataset from Sullivan manual's calculation example.

A description of the variables in the dataset from Sullivan manual's
calculation example.

## Usage

``` r
description_sullivan
```

## Format

A data frame with 2 variables:

- heading:

  name of the variable in the sullivan dataset

- description:

  description of the variable from the sullivan dataset
